# 소윤 로블록스 레전드 🎮🎁 — 초5 2학기 공부 퀘스트

초등학교 5학년 **2학기 수학·과학·사회(한국사)** 를 과목별 완성표로 공부하는 **게임형 학습 웹앱(PWA)** 입니다.
매일 유튜브로 배우고 **완료 체크**, 단원마다 **확인문제(10문항)** 와 과목 끝 **총정리(20문항)** 로 복습하며,
용돈(한국 원)을 모아 **목표 20000원(2만 원)** 달성이 최종 미션이에요. (로블록스 컨셉·계급 진급)

## ✨ 기능
- **과목 탭 3개**: 수학 · 과학 · 사회(한국사) — **각 14일 완성표**(총 42일), 초5 2학기 전 범위
- 날짜별 **유튜브 검색 버튼** + **완료 체크**
- **단원마다 확인문제 10문항**(Day 3·6·9·12) + 과목 끝 **총정리 20문항**(Day 14) — **채점하면 정답과 해설(💡)이 표시돼 바로 복습**
- **80점 미만이면 '영상 다시 보기'를 눌러야만 재도전** 가능(유튜브 재시청 유도)
- **목표 20000원(2만 원) 게이지** · 계급 진급(뉴비→로블록스 레전드) · 만점 ⭐
- **역할 선택**: 소윤(학생) / 엄마 · 아빠(보호자)
- 보기 순서를 섞어 정답 위치가 매번 달라져요(찍기 방지)

## 💾 저장 방식 (중요)
- 진행상황은 **기기(브라우저 localStorage)에 우선 저장**됩니다 — 소윤이 폰에서는 **안전하게 유지**되고 매일 지워지지 않아요.
- **3인 실시간(엄마·아빠가 다른 폰에서 실시간 보기)** 은 **무료 Firebase Realtime Database** 를 연결하면 켜집니다. (아래 참고)
- 편집 패널의 **백업/복원 코드**로 언제든 진행상황을 내보내고 되돌릴 수 있어요.

### Firebase 연결(선택, 3인 실시간용)
1. https://console.firebase.google.com 에서 프로젝트 만들기(무료)
2. **Realtime Database** 만들기 → 위치 선택 → **테스트 모드**로 시작
3. 데이터베이스 URL 복사 (예: `https://xxxx-default-rtdb.firebaseio.com`)
4. `index.html`(또는 소스) 상단의 `var FIREBASE_DB = "";` 에 그 URL을 넣기
   → 저장하면 3인 실시간 동기화가 켜집니다.

## 🛠 기술
- 순수 HTML/CSS/JavaScript 단일 페이지 · **PWA**(오프라인 캐시)
- 저장: `localStorage`(기기 우선) + 선택적 **Firebase RTDB**(3인 실시간)
- 보상: 하루 200 + 단원 확인문제 800 + 총정리 1000 = 목표 **20000원(2만 원)**(모두 완료 시 21000원)
